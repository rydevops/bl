# Blocklands

A tiny Minecraft-style voxel sandbox that runs in the browser, installs as a PWA and plays offline.
Everything - terrain, textures, icons, sound effects and music - is generated by code. There are no art or audio assets.

**Scope:** a generated world (dirt, grass, sand, stone, river water, four tree species), an inventory,
crafting a pickaxe, an axe and a 3x3 hammer, trees that **fall over and drop their items** when you break the bottom log,
**health, hunger and saturation**, apples, and **saplings** that grow back into trees.

## Play

| | Touch | Keyboard + mouse |
|---|---|---|
| Move | drag on the left half (floating joystick) | `W A S D` |
| Look | drag on the right half | mouse (click to capture) |
| Mine / attack | hold the **Attack** button (slide your thumb to aim), or hold still on the right half | hold left mouse |
| Place / use | tap the **Use** button, or tap the right half | right mouse |
| Jump / swim up | the arrow button | `Space` |
| Sprint (needs 3 full drumsticks) | push the joystick past its ring | `Shift` |
| Eat | select an apple, tap **Use** | right mouse |
| Inventory | backpack button | `E` |
| Hotbar | tap a slot | `1`-`9` or mouse wheel |
| Pause / settings | pause button | `Esc` |
| Answer a maths question | tap the number pad, **OK** (or **Cancel**) | digits, `Enter`, `Backspace`, `Esc` to cancel |

**Worlds:** *Play* opens the world list. Create as many worlds as you like (name and optional seed), switch between them,
and delete the ones you no longer want. Each world saves its own edits, inventory and position in the browser.

**First minutes:** punch a tree trunk at the bottom. The whole tree topples, so walk over the logs to collect them.
Open the inventory, tap *Planks* in the recipe book (it fills the grid), tap the result slot, then do the same for
*Stick*, *Wooden Pickaxe* and *Wooden Axe*. Long-press the result to craft as many as your materials allow.
Stone only drops cobblestone when mined with a pickaxe.

**Hammers:** a *Wooden Hammer* (5 planks + 2 sticks) or *Stone Hammer* (5 cobblestone + 2 sticks) breaks a **3x3 square** of blocks
around the one you aim at, in the plane of the face you are looking at (a wall for a wall, a flat patch for the ground).
Craft it with a full row of head, then head-handle-head, then the handle centred below:

```
P P P
P S P     P = planks (wooden) or cobblestone (stone), S = stick
. S .
```

A hammer harvests stone like a pickaxe of the same material, but mines at half the speed and lasts twice as long;
every block it breaks costs one use. It leaves water, saplings, logs and planks alone (those need an axe or pop off by themselves).
With the maths switch on, a hammer only takes along blocks of the unlocked type.

**Survival:** the bars above the hotbar are health (hearts), hunger (drumsticks) and, thin and amber, saturation.
Hunger drops by half a drumstick for every 15 seconds spent mining, chopping, sprinting, swimming or jumping.
With hunger full and saturation left you heal; when saturation runs out healing stops until you eat. At zero hunger you starve
(half a heart every 5 s), and a hard fall hurts. If you die you drop everything where you fell: respawn and go and get it (15 minutes).

**Trees:** spruce, oak, maple and darkwood. Breaking leaves gives apples, sticks (15%) and a sapling of that tree (10%) but never leaf blocks.
Plant a sapling in **dirt** (not grass) and stay nearby: it grows into a tree within a couple of minutes. Worlds from before v0.3 stay spruce-only.

**Maths mode (grade 1):** to mine a block you must first earn its type. Try to mine a type that is not the *unlocked* one
and a question appears (additions and subtractions with answers from 0 to 20). Tap the number pad and press **OK**.
A right answer unlocks that type: mine as many as you like with no more questions. Only one type is unlocked at a time, so
mining something else asks again (and locks the old one). **Cancel** closes the question and changes nothing.
A wrong answer turns the block into a lit **TNT** that blows up after 3 seconds: it carves out a sphere of land (radius 3.5)
and leaves no blocks to pick up, and it hurts a little (never fatal) if you stay close. Saplings pop off without a question.
The chip at the top of the screen shows the unlocked block. Switch maths off in the pause menu if you want plain mining.
The unlocked block and any burning TNT are saved with the world.

In the inventory a tap picks a stack up / puts it down; a long-press (or right click) takes half / places one.

## Deploy to GitHub Pages

1. Unzip `blocklands-v<version>.zip`. It contains the flat `deploy/` contents (11 files, no folders).
2. Put those files in the root of the branch/folder GitHub Pages publishes (for example the `gh-pages` branch, or `/docs`),
   and enable *Settings -> Pages*.
3. Open `https://<user>.github.io/<repo>/`. All URLs are relative, so a project sub-path works. The `.nojekyll` file disables Jekyll.

Or let GitHub build it: push this source repo and enable *Settings -> Pages -> Source: GitHub Actions*;
`.github/workflows/pages.yml` runs the tests, builds and publishes `deploy/`.

Updating: every build changes the service-worker cache name, so installed apps pick up the new version on the next launch.

## Develop

Requires Node 20+.

```bash
npm install          # only dependency: esbuild (dev)
npm test             # node:test suite (core rules + build output)
npm run build        # writes deploy/
npm run serve        # http://localhost:8080 serves deploy/
npm run package      # build + dist/blocklands-v<version>.zip (+ source zip + SHA256SUMS.txt)
npm run release:patch   # or release:minor / release:major / `npm run release -- 1.2.3`
```

`npm run release` bumps the semantic version in `package.json`, adds a stub to `CHANGELOG.md`, runs the tests
(aborting and restoring the version if they fail), builds, packages, and creates an annotated `v<version>` git tag when run inside a git repository.
Edit the changelog entry before publishing.

Optional real-browser check (needs `puppeteer-core` and a Chromium via `CHROME_PATH` or `@sparticuz/chromium`):
`npm run build && node scripts/browser-smoke.mjs`. It loads the built PWA on a phone-sized touch viewport, checks the service worker
and offline reload, then chops a tree, collects the drops, crafts both tools, eats, sprints, plants and grows a sapling, and dies and respawns through the UI.

## How it is put together

```
src/core/     headless game: blocks, terrain, world/chunks, physics, mining, inventory, crafting,
              falling trees, maths questions, TNT, entities, sky, mesher, procedural textures/icons/music (no DOM)
src/client/   browser layer: WebGL renderer, input (touch + desktop), WebAudio, DOM UI, storage, main loop
static/       index.html + style.css
scripts/      build, package, release, serve, zip/png writers, browser smoke test
test/         node:test suites (the core is tested by driving Game directly, no browser needed)
```

The game core never touches the DOM, so the same `Game` class that the browser drives is what the tests drive.
The falling-tree rule: after any block is removed, logs near the change are flood-filled; a group with no solid, non-tree
block beneath it is "floating". Its leaves are claimed by the nearest log, and the group becomes a rigid body that pivots about its
far bottom edge, away from the player, then comes to rest on the terrain and turns into item drops.
